# Fire Blast particle sources

- Kenney, **Particle Pack**, https://kenney.nl/assets/particle-pack — CC0.
- Download: https://kenney.nl/media/pages/assets/particle-pack/f8fe0f8cb8-1677578741/kenney_particle-pack.zip
- Unmodified transparent PNGs: `fire_01.png`, `smoke_01.png`, `spark_05.png` (512×512). Color is supplied at runtime. Original license included.
- Rendered with the installed Babylon Lite facing-billboard API, using fixed pools.

The neighboring `training-dummy.glb` is extracted from this project's `public/moonwell.glb` (node `Dummy`) using `scripts/ashen-reach/extract-dummy.mjs`. Geometry and material assignments are preserved; textures resized to at most 256px. This is an existing project prop, not part of the Kenney download.
