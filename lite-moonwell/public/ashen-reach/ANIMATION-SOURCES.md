# Added animation sources

The five directional/turn animations added to `wanderer.glb` are by Quaternius,
licensed CC0-1.0: https://quaternius.itch.io/universal-animation-library

Public distribution: https://cdn.tosijs.net/quaternius/UAL1_core.glb
Distribution reference: https://3d.tosijs.net/CHANGELOG/

They were retargeted offline using the MIT BJS Character Controller V2 retargeter.
See `animation-provenance.json` for hashes and the pinned upstream commit, and
`scripts/vendor/bjs-retarget/LICENSE` in the repository for the code license.

This attribution concerns the five added clips, not a relicensing of the complete
Human model, earlier source rig or pre-existing assets. Their provenance remains
documented in the repository's source-motion recovery and character asset docs.
