# Optional independent visual review

Use only when independent review is requested or a bounded review has current authorization. It is not a required stage of every Dream Loop iteration.

Supply the user's reference, current live captures/video, the specific intended outcome and relevant constraints. Keep the reviewer independent from the implementation where feasible. Ask for the most consequential observable mismatches, with evidence and actionable changes. A material defect can override green tests; a score is not user acceptance.

Keep review scoped to the deliverable: composition/materials/atmosphere for scenes, anticipation/action/recovery for animation, charge/release/flight/impact for spells. Do not require a perfect pixel score, giant gap list or repeated judge rounds once the task's substantive acceptance is met.
