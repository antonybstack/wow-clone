The armory **Orc** is the print-sculpt retopo, not a MakeHuman warp. Pipeline: [orc sculpt pipeline](orc-sculpt-pipeline.md).

- Form: `blender/characters/sources/orc-print/Orc_22.fbx` (Crayon, CC-BY 4.0). Look: `.agents/skills/blender-lite/references/orc-concept-art.png`.
- Bind: Mixamo T-pose, 65 joints, 55 clips, pelvis-only loincloth weights. Pack: `public/ashen-reach/equipment-orc/` with the same eight catalogue garments as Human. Gloves are an inflated limb shell of the print hand/forearm/distal arm (Human Toigo cuffs are too short to grade). - Remaining polish: idle thoracic stoop is Mixamo idle on the print chest (T-pose rest is upright enough; no clip-fighting spine hack), chin pad still a slight pale catch. Gauntlet leather uses a smart-projected grey glove albedo, so it reads as a wrapped leather sleeve rather than stitched Toigo gloves. A sliver of inner-armpit skin can still show at the vestment/gauntlet seam in armory close-ups. Do **not** add a runtime wrap engine. Factory props already have an Orc grip correction (×1.16 and a short palm nudge); Mixamo two-hand carry still reads as a pole across the chest. Loincloth inner crotch loops filled 2026-09-19. Garment fit rebuilt 2026-09-19 on the single fitter above: boot roughness p99 28 mm to 7 mm, boot penetration 136 to 20 vertices of 3530, and the shredded toe cap and lace are gone.
