# Conservative layer coverage — execution after the wardrobe source checkpoint

The fixed-pose Wayfarer control reproduces the Lector candidate's rear trouser and front skin breaches. Further global transfers, offsets and body-shaped cloth have failed. Use the existing modular coverage system and native glTF meshes to remove only surfaces completely covered by an equipped layer. This is an implementation plan, not acceptance of the new designs.

1. **Derive geometry without changing the source master.** Keep the canonical body, neutral garments, 65-joint bind and 57 source curves intact. After Human shape baking, partition triangle indices into an exposed mesh and a conservative torso core. Share every original position, normal, UV, skin and morph accessor. Each original triangle must occur exactly once with the same winding. Do not reindex vertices, resculpt the body, prune the source used by fitting, or change physics. Derive boundaries from the actual rig, with neck, shoulders, hands and trouser seam left exposed. Keep output in `.cache` until reviewed.
2. **Prove independent layer rules.** Use the existing semantic body coverage adapter and streamed visibility commit. Human and Undead need actual independently hideable torso cores; Orc already has physical regions. A trousers core may hide only beneath a declared long torso garment. Define an explicit garment-region vocabulary and validate it in the catalogue; a cropped top or bare torso must retain the trousers. Restore every part on unequip. Do not hide an entire fused body or all trousers. Preserve cancellation, failed-fetch restoration, shared skeleton ownership and disposal.
3. **Audition before advertising.** Add a bounded developer switch with fixed compiled assets and exact adapters. It must reject unsupported head variants and preloaded paths. Compare original and candidate at identical camera/shape/motion phases, including the confirmed Human stout and Undead cases. Review neutral/slender/stout Human at 0.90/1.15 height, neutral Orc/Undead, all equipped and bare states, source run/jump/land/casts/sword/turn, and mixed torso/legs. An index union proves completeness only when both parts are visible; it does not establish hidden-part coverage under motion.
4. **Make any publication explicit.** Accepted geometry has a coverage revision in manifests, factory provenance and actor cache identity. Compile coverage from each actual body's topology; never apply M1 indices to M5's different identity topology. Freeze catalogue v3 and migrate known recipes explicitly if new IDs are introduced. Publish full and compact per-item immutable files before advertising them. The wardrobe source descriptors remain candidate-only until their own live fit reviews pass.
5. **Measure the consequence.** Additional parts can add draws and duplicate runtime vertex allocations despite shared glTF accessors. Measure rather than assume a benefit: isolated M1 Max Chromium WebGPU, 1280×720, seven enemies, three 12-second runs for each of five routes; separate recording. Run twenty fresh compressed 50 Mbit/s, 40 ms starts for default and largest saved appearance, retaining all GPU-first-use outliers. Recheck shadows, cathedral traversal, native mobile fallback, WebKit, load failure, latest-request wins and disposal. Phone/public-player gates remain distinct.
6. **Integrate the actual factory and remote path.** Only after five distinct designs fit, add their catalogue IDs and immutable full/compact fits. Extend the bounded remote preparation path with real per-piece composition and compatible source palettes; current whole-outfit two-fit proof assets do not establish remote armor. Prove remote swaps, late loads, rejection and churn, then perform production gates and release. M5 headwear remains a separate fit gate before identity publication; M8 must still address the failed 100-actor region workload.

References: [glTF mesh and index semantics](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html#meshes), [skin attributes](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html#skinned-mesh-attributes), [glTF Transform Primitive](https://gltf-transform.dev/modules/core/classes/Primitive), and the project's `coverage-contract.js` and `equipment-stream.js`. No custom skinning or runtime mesh rebuilding is required.
