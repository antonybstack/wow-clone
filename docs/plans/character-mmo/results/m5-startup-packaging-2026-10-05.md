# M5 native startup packaging and isolated timing

**Implemented locally; M5 remains open and unreleased.** Native Rolldown packaging
reduces the ordinary main entry's preload list from 20 to eight. Six final local
cold cohorts finish **120/120 within one second**, with the actual saved identity,
body shape, clothing and native playable motion present at first play. This is a
local compressed ordinary build, not public-CDN or physical-phone acceptance.
All 286 measured art/physics payloads remain byte-identical to `ce63e62`.

## Change and why

The unchanged largest saved ponytail pilots took **2930.2 / 1041.7 / 1033.4 ms**;
three default pilots took **887.2 / 891.6 / 889.6 ms**. The selected decoder/body
request queued behind many static module preloads in the local HTTP/1.1 waterfall.
A native high-priority module-preload hint did not help: **1132.6 / 1043.2 / 1036.8 ms**.
It is removed. The earlier multi-second first-use GPU tail is distinct and remains
unexplained; later passing rows do not erase it.

The bundler uses [native groups](https://rolldown.rs/reference/TypeAlias.CodeSplittingGroup)
and [static graph information](https://rolldown.rs/reference/Interface.ChunkingContext)
to group the normal main entry's existing application dependencies. Optional saved
storage/descriptor code stays separate. Pure equipment, dye and coverage values
stay in `appearance-common`, keeping identity validation independent of Lite/GPU
initialization. Native strict execution ordering creates entry facades; guards
follow the graph while enforcing one source owner for shared early/main loaders.
Both descriptor/storage closures refuse accidental eager renderer or shared-region
imports. The compiled identity provenance is asserted in its actual owner chunk.
`ASHEN_BOOT_BUNDLE=0` disables this boot group only, not every historical setting.

No custom loader/cache, renderer, mixer or skinning system was added. Geometry,
textures, physics, approved face, 65-joint bind and playable curves are unchanged.
The ordinary measured build has 832 artifacts / 338 exact filtered critical
resource comparisons. JS references/maps change with packaging. The **separate
native Pages staging build** has 514 artifacts (513 served comparisons; `_headers`
is configuration), with 20 verified identity and five region cache policies.
These two output seals are preserved separately and are not interchangeable.
