# M2 — private Lite bridges contained on 1.28.0

This checkpoint follows the [1.31.1 migration plan](babylon-lite-1.31.1-migration-plan.md) before changing the dependency. Sun CSM, far PCF, and the two local PCF maps now check the Lite version and the private fields they require. Their setup registers one early, idempotent cleanup path, including partial failures. The paths track texture acquisition, retire frame-graph tasks once, guard late preload and receiver callbacks, and preserve the GPU submission fence for CSM caster replacement. The CSM receiver texture remains borrowed by materials; this bridge releases the generator's final acquired reference at teardown because Lite exposes no generator disposer. The plugin-free local caster alias remains necessary to avoid a caster sampling its own depth attachment. Source comments link the [CSM](https://github.com/BabylonJS/Babylon-Lite/blob/npm-lite-v1.31.1/docs/lite/architecture/17-cascaded-shadow.md) and [frame-graph](https://github.com/BabylonJS/Babylon-Lite/blob/npm-lite-v1.31.1/docs/lite/architecture/28-frame-graph.md) contracts.

Socket and animation reads of Lite's glTF mixer, palette, bone node index, and debug world matrix now pass through `lite-skin-layout.js`. Loaded skinned actors fail with a useful layout error if the expected 1.28.0/1.31.1 structure changes; loading and optional bones remain nullable. The adapter retains the existing palette/inverse-bind/mesh-world transform order and links the [skeleton contract](https://github.com/BabylonJS/Babylon-Lite/blob/npm-lite-v1.31.1/docs/lite/architecture/13-skeleton.md).

`scripts/test-shadow-bridge-lifecycle.mjs` and `scripts/test-lite-skin-layout.mjs` pass nine focused cases, including partial setup, pending CSM fence/local preload, repeated teardown, 1.31.1 version acceptance, and joint-world reconstruction.
