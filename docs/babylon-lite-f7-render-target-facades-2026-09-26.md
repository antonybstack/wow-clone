# F7 — sampled render-target facades (2026-09-26)

The main HDR scene target now uses Lite 1.31.1 `createSurfaceRenderTargetTexture(..., withSampledDepthTexture)`. Its scene render task owns `.rt`; contact, fog and the direct display path borrow resize-aware sampled color or depth facades. The contact composite also uses a surface facade; its effect task owns `.rt`, and fog borrows `.texture`. Both constructors call `disposeRenderTargetTexture` only if task construction fails before ownership transfer. These choices follow the [Lite frame-graph render-target ownership contract](https://github.com/BabylonJS/Babylon-Lite/blob/npm-lite-v1.31.1/docs/lite/architecture/28-frame-graph.md).

The small ambient-occlusion and fog integration targets remain explicit `createRenderTarget` targets. Their existing dimensions use `ceil(source / 2)`; Lite's surface scale resolves with `floor(canvas * scale)`, which changes odd-height portrait results and needs a separate comparison before replacing them. The bloom task returns a borrowed output target, so the display pass retains its narrow raw-view binding for that path; wrapping it in a second owning facade would give the attachment two owners. Contact-shadow output is likewise borrowed from Lite's task. This bounded F7 trial removes private view reads from the main scene and contact-to-fog path without changing those ownership rules.

Two focused facade/lifetime tests and the production build pass. Live contact/ambient checks passed at feet, stones and town street, including exact disabled bypass, 10.57 m keyboard movement and 390×844 portrait resize. Fog matched all 45 independent shadow samples, remained cached when stationary, moved 4.92 m and resized its portrait integration target. HDR, mobile touch, injected depth fallback and desktop WebKit passed with no runtime or GPU errors; WebKit moved 17.31 m with active Havok. A stale fog-probe assertion for V25's removed decorative ridge was limited to runs where that old caster exists.

The reviewed [19.511-second contact on/off MP4](https://ve.sparkify.dev/wow-clone/ashen-reach/lite1311-f7/2026-09-26-contact-facade-motion.mp4) shows both effects toggled in the churchyard, normal movement, then the town street. Its 1,742 timestamped frames encode at 1280×720 with square pixels and elapsed time preserved. The capture had zero runtime or GPU errors.
