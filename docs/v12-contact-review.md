# V12 contact review — 2026-09-24

Source-only review of current `contact-occlusion.js`, `post.js`, and installed Lite 1.28. No browser or runtime validation; only this review file was written.

- **Previous normal-sign bug is fixed:** `normalAt` uses `cross(dx,dy)` and faces the normal toward the camera. The earlier finding is superseded.
- **Border derivative defect is fixed in source:** explicit one-sided differences at all four texture edges replace the clamped zero derivative. Edge behavior at even and odd resolutions still awaits the parent's runtime verification.
- **Fullscreen viewport limitation:** this implementation assumes a camera covering the entire source target. Custom reconstruction uses full-target aspect and UVs, ignoring camera viewport dimensions/offsets; native contact adjusts aspect but also reconstructs from full-texture UVs. Non-fullscreen viewports require matching viewport-relative reconstruction and sampling across both paths. Portrait resizing of a fullscreen viewport remains within the intended scope.
- **Camera proxy is compatible with the inspected Lite helpers:** reads and cache writes both reach the current `scene.camera`. Identity changes increment `resetVersion`; no stale-camera capture defect found in this adapter.
- **Temporal configuration:** `temporalWeight: 0, temporalSamples: 1` produces effective current-frame weight 1 and phase 0. It prevents history blending, but still allocates history and runs producer, resolve, and history-copy draws. The nine-tap spatial filter remains; `spatialRadius: .8` adds no phase displacement with one sample. “No frame history” overstates the optimization.
- **Composition is wired correctly:** `composition: 'none'` supplies occlusion in `.r`; the custom composite applies its own strength. Current graph order produces scene depth, native contact, AO, composite, then fog.
- **Resize/disposal:** full graph recording refreshes contact/depth/color views before the consumer records. Native disposal owns contact raw/stable/history targets; AO/composite task disposal releases their targets, and wrappers release effect buffers. No concrete ownership leak found on normal full-scene disposal. Detached task replacement still needs explicit disposal.
- **Singular inverse failure is fixed in source:** `update()` no longer throws when inversion returns null; it disables the custom effect through the uniform flag. AO returns zero before reconstruction, the composite passes through source color, and native contact clears its output. Recovery remains a runtime check.
