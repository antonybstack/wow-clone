# Stone normal and roughness

Source: [Rock Wall 08](https://polyhaven.com/a/rock_wall_08), Amal Kumar, Poly Haven, [CC0](https://polyhaven.com/license).

`stone-detail.png` is generated by `node scripts/ashen-reach/prepare-stone-detail.mjs` from the 1k `nor_gl` and `rough` JPEGs. RGB contains an OpenGL tangent-space normal; alpha contains linear roughness. The generator resizes to 512×512 and renormalizes normals. Upload as linear RGBA data with mipmaps; do not apply sRGB decoding to any channel. Alpha is data, not transparency. Existing diffuse texture/palette remain unchanged.
